# 📷 V4L2 命令速查

## 设备信息

```bash title="查询设备能力"
v4l2-ctl -d /dev/video0 --all
```

```bash title="列出所有视频设备"
v4l2-ctl --list-devices
```

```bash title="查询驱动信息"
v4l2-ctl -d /dev/video0 -D
```

## 格式相关

```bash title="列出支持的所有格式"
v4l2-ctl -d /dev/video0 --list-formats-ext
```

```bash title="查看当前格式"
v4l2-ctl -d /dev/video0 --get-fmt-video
```

```bash title="设置格式"
v4l2-ctl -d /dev/video0 --set-fmt-video=width=1920,height=1080,pixelformat=YUYV
```

```bash title="常用像素格式"
# YUYV422
pixelformat=YUYV

# NV12
pixelformat=NV12

# MJPEG
pixelformat=MJPEG

# H.264
pixelformat=H264
```

## 采集测试

```bash title="MMAP 方式采集 10 帧"
v4l2-ctl -d /dev/video0 --stream-mmap --stream-count=10
```

```bash title="采集并保存为文件"
v4l2-ctl -d /dev/video0 --stream-mmap --stream-count=1 --stream-to=output.yuv
```

```bash title="显示帧率"
v4l2-ctl -d /dev/video0 --stream-mmap --stream-count=100 --verbose
```

```bash title="指定缓冲数量"
v4l2-ctl -d /dev/video0 --stream-mmap --stream-count=10 --buffer-count=4
```

## 控件 (Controls)

```bash title="列出所有控件"
v4l2-ctl -d /dev/video0 --list-ctrls
```

```bash title="列出所有控件（含菜单）"
v4l2-ctl -d /dev/video0 --list-ctrls-menus
```

```bash title="获取控件值"
v4l2-ctl -d /dev/video0 --get-ctrl=brightness
v4l2-ctl -d /dev/video0 --get-ctrl=exposure
```

```bash title="设置控件值"
v4l2-ctl -d /dev/video0 --set-ctrl=brightness=128
v4l2-ctl -d /dev/video0 --set-ctrl=exposure=1000
v4l2-ctl -d /dev/video0 --set-ctrl=auto_exposure=1
```

```bash title="常用控件"
brightness       # 亮度
contrast         # 对比度
saturation       # 饱和度
hue              # 色调
exposure         # 曝光
gain             # 增益
auto_exposure    # 自动曝光 (0=手动, 1=自动)
white_balance    # 白平衡
```

## 状态与调试

```bash title="查看设备状态"
v4l2-ctl -d /dev/video0 --log-status
```

```bash title="订阅事件"
v4l2-ctl -d /dev/video0 --subscribe-event=all
```

```bash title="查看缓冲信息"
v4l2-ctl -d /dev/video0 --query-buffers
```

## Media Controller

```bash title="列出 Media 设备拓扑"
media-ctl -d /dev/media0 --print-topology
```

```bash title="查看实体信息"
media-ctl -d /dev/media0 --print-dot
```

```bash title="配置链路"
media-ctl -d /dev/media0 --set-link '"imx477 2-001a":0->"rkisp1_isp":0[1]'
```

```bash title="设置子设备格式"
media-ctl -d /dev/media0 --set-v4l2 '"imx477 2-001a":0[fmt:YUYV8_2X8/1920x1080]'
```

## I2C 工具

```bash title="扫描 I2C 总线"
i2cdetect -y 1
```

```bash title="读取寄存器（16位地址）"
i2cget -y 1 0x1a 0x00 w
```

```bash title="写入寄存器"
i2cset -y 1 0x1a 0x00 0x01
```

## 常见问题排查

```bash title="DQBUF 超时 → 先查 Sensor 链路"
# 1. 检查 I2C
i2cdetect -y 1

# 2. 检查设备树匹配
ls /sys/firmware/devicetree/base/

# 3. 查看驱动日志
dmesg | grep -i "v4l2\|isp\|mipi\|sensor"

# 4. 查看 ISP 状态
v4l2-ctl -d /dev/video0 --log-status
```
