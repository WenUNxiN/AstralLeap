# Linux 相对路径与绝对路径

::: info 这是格式示例
本页示范如何把一个小知识点整理成笔记。下面的目录用于说明路径含义，命令输出按实际设备记录。
:::

## 想弄清的问题

为什么同一条命令在不同目录下运行，会访问到不同的文件？

## 关键概念

Linux 中，以 `/` 开头的是绝对路径，从根目录开始解析；相对路径从进程的当前工作目录开始解析。

假设当前目录是 `/home/user/project`：

| 路径 | 对应位置 |
| --- | --- |
| `/home/user/project/main.c` | 明确指定的绝对路径 |
| `main.c` | 当前目录下的 `main.c` |
| `./main.c` | 同样是当前目录下的 `main.c` |
| `../notes.md` | 上一级目录中的 `notes.md` |

## 自己的理解

可以先问两个问题：路径是否以 `/` 开头？如果不是，当前工作目录在哪里？

命令、脚本或程序的位置与当前工作目录需要分别看待。使用相对路径时，先确认当前工作目录，更容易判断它将访问哪个位置。

## 查看命令

```bash title="确认工作目录与相对位置"
pwd
ls .
ls ..
```

`pwd` 显示当前工作目录，`.` 表示当前目录，`..` 表示上一级目录。可以把自己执行命令时的输出补在这里。

## 待验证

- [ ] 在两个不同目录执行 `pwd` 和 `ls .`，观察输出变化。

## 参考

可以通过本机的 `man pwd` 查看命令说明；没有安装手册的开发板可在开发电脑上查阅。
