## 查看系统信息

```bash
# 查看内核名称。
uname -s

# 查看正在运行的内核版本。
uname -r

# 查看机器架构。
uname -m
```

| 参数 | 含义 |
| --- | --- |
| `-s` | 内核名称 |
| `-r` | 内核版本 |
| `-m` | 机器硬件名称或架构 |

常见输出：Linux 系统的 `uname -s` 通常显示 `Linux`；`uname -r` 显示内核版本字符串；`uname -m` 可能显示 `x86_64`、`aarch64` 等架构名称。这些是输出含义说明，实际值以当前设备为准。

## 确认当前位置与文件

```bash
# 显示当前工作目录。
pwd

# 以详细列表查看当前目录，并使用便于阅读的文件大小。
ls -lh
```

| 命令或参数 | 含义 |
| --- | --- |
| `pwd` | 输出当前工作目录的绝对路径 |
| `ls -l` | 显示权限、所有者、大小、时间等详细信息 |
| `ls -h` | 配合详细列表，以 K、M 等单位显示大小 |

常见输出：`pwd` 输出一条目录路径；`ls -lh` 输出当前目录下的文件和子目录信息。详细列表中，行首的 `d` 表示目录，`-` 表示普通文件。

## 查看文件系统空间

```bash
# 查看已挂载文件系统的容量与使用情况。
df -h
```

`-h` 使用便于阅读的容量单位。常见输出列包含总容量、已用容量、可用容量、使用比例和挂载点；列名可能因系统语言和工具实现不同而变化。

## 使用注意

- 以上命令用于查看信息，不需要 `sudo`。
- 开发板上的 BusyBox 与电脑上的 GNU 工具可能支持不同参数；遇到参数错误时先查看该工具的帮助。
- 输出会随设备和当前目录变化；需要留档时记录自己的原始输出与运行环境。
