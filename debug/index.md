## Debug 记录模板

每篇记录统一包含：

1. **现象** — 问题表现、错误信息
2. **环境** — 平台、内核、SDK 版本
3. **错误日志** — 完整日志信息
4. **初步判断** — 可能的原因列表
5. **排查过程** — 一步步验证的过程
6. **根因** — 问题的根本原因
7. **解决方案** — 具体修复方法
8. **验证** — 修复后的验证结果
9. **经验总结** — 类似问题的排查思路
10. **相关知识 / 实验** — 关联链接

---

::: tip 重要原则
错误信息必须同时保留文本，不要只放截图。未来搜索系统才能检索到。
:::
