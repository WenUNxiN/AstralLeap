## 常见问题方向

### 缓冲相关
- DQBUF 超时（最常见）
- 缓冲申请失败
- mmap 映射失败
- 丢帧

### 格式相关
- 设置格式失败
- 实际输出格式与设置不符
- stride 与 width 不一致
- 花屏/颜色不对

### 控件相关
- 曝光设置不生效
- 增益范围不对
- 控件值读取失败

---

::: tip 常用调试命令
```bash
# 查看设备能力
v4l2-ctl -d /dev/video0 --all

# 查看支持的格式
v4l2-ctl -d /dev/video0 --list-formats-ext

# 查看所有控件
v4l2-ctl -d /dev/video0 --list-ctrls

# 查看设备状态
v4l2-ctl -d /dev/video0 --log-status
```
:::
