✨ 更多增强建议

锦上添花的体验优化

🔍

搜索增强

使用 Algolia DocSearch 替代本地搜索，支持模糊匹配与键盘导航

🌓

暗色/亮色主题

添加主题切换按钮，让用户在深色科技风和浅色阅读模式间切换

📡

RSS 订阅

生成 RSS feed，让关注者可以通过阅读器跟踪新文章发布

🎯

返回顶部

长文章页面添加滚动进度条与返回顶部按钮，提升长文阅读体验

🏷️

标签云

博客首页展示标签云，支持按标签快速过滤文章

📈

Analytics

集成 Google Analytics 或 Umami，了解访客来源与阅读偏好

⚡ 性能优化

提升页面加载速度与运行性能

🖼️

图片懒加载

文章内图片添加 loading="lazy"，首屏只加载可见区域图片，减少初始请求

✨

星空背景启用

StarfieldBackground 组件已编写但未在 Layout 中引用，启用后增强视觉深度

📦

组件按需加载

Discussion、PageViewCounter 等组件可改为动态导入，避免首屏 JS 过大

🚀

CDN 与缓存

GitHub Pages 已自带 CDN，可添加长期缓存头与资源预加载 hint
